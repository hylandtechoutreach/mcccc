# Command Line & Python
This lesson introduces the command line, and shows how to use Python to create a terminal-based Choose Your Own Adventure game.

## Warm-Up: Terminus
[Click here to play the game!](https://web.mit.edu/mprat/Public/web/Terminus/Web/main.html)

### Challenges
Try to complete each of these challenges:

- Make it to a dead end
- Move `PracticeDummy4` into the `Box`
- Talk to a `Pony`
- Meet a `HurryingStudent`
- Make it into `AthenaCluster`
- Make it into `TownSquare`
