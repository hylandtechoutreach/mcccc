# Command Line & Python
This lesson introduces the command line, and shows how to use Python to create a terminal-based Choose Your Own Adventure game.

### Agenda

| Activity | Time
|-|-|
| Warm-Up | 10m |
| Presentation | 5m |
| Code-Along | 30m |
| Debugging | 5m |
| Formative Assessment | 10m |

## Warm-Up: Terminus
Have students play the [Terminus game](https://web.mit.edu/mprat/Public/web/Terminus/Web/main.html). There are some challenges listed on the [lesson homepage](StudentDesc.md).

## Presentation: Command Line + Python
Present the [PowerPoint Presentation](CommandLinePy.pptx) to go over some basic information. This should be kept relatively quick.

## Code-Along: CHOOSE YOUR OWN ADVENTURE
Follow [the instructions](PythonCyaCodeAlong.md) to facilitate the code-along activity. There's quite a bit of code to type, and quite a few concepts covered, but the understanding is less important than getting a working program.

## Debugging
Facilitate the [debugging activity](Debugging.md) as a group. Put the projects up on the projector, and have students try to spot the issues in the code.

## Formative Assessment
Facilitate the [Blooket Quiz](https://dashboard.blooket.com/set/6a91afc392e998663052d67f).
