# p5.js
This lesson introduces the JavaScript version of the Processing library for Creative Coding. It is entirely based on content from the [Coding Activities Library](https://github.com/hylandtechoutreach/coding-activities).

### Agenda

| Item | Time |
|-|-|
| Presentation | 20m |
| Formative Assessment | 10m |
| Micro Lessons | 30m |

## Presentation
Present the [introductory presentation](https://docs.google.com/presentation/d/1qI1nRh0afxfExw-63fHfYYUENfr_1iH_l5vfA4gFNW0/edit?slide=id.g3e30cf105d4_2_293#slide=id.g3e30cf105d4_2_293) - note that there are several interactive components.

## Formative Assessment: Gimkit
Facilitate the [Gimkit Quiz](https://www.gimkit.com/view/65fc762f3ee6c3002c0db3c3) covering the content from the presentation. Students can have some time to practice the questions before the game begins using the link on the [lesson homepage](StudentDesc.md).

## Micro Lessons
Go through as many of the small lessons as it makes sense to do. Instructions:

- [Cube Image](https://hylandtechoutreach.github.io/coding-activities/ProcessingMicroLessons/CubeImage.html)
- [Mouse Drawing](https://hylandtechoutreach.github.io/coding-activities/ProcessingMicroLessons/MouseDrawing.html)
- [Mood Swings](https://hylandtechoutreach.github.io/coding-activities/ProcessingMicroLessons/MoodSwingBoolean.html)
- [Scratch Reveal](https://hylandtechoutreach.github.io/coding-activities/ProcessingMicroLessons/ScratchReveal.html)
