# Vibe Coding
it's just vibes

## Get Started
Follow these steps to begin:

1. [Create a new project in HyTop](https://hytop.onrender.com/create-project)
1. Go to [ChatGPT](https://chatgpt.com)
1. Ask it to generate a website about a topic
1. Copy and paste the HTML code provided into the HyTop project
1. If there is a **style.css** section, create a new **style.css** file in HyTop and paste the code there
1. If there is a **script.js** section, create a new **script.js** file in HyTop and paste the code there

## Updates
Once the base exists, continue to ask ChatGPT for help building and altering the site. You can ask ChatGPT to do things like:

- Change the font to something cool
- Change the colors to something better
- Change the layout so sections appear differently
- Add additional pages to the site
- Add links to other sites
- Add a game on the page
- Add a new picture to the page
- Add a button to the page to make it do something
- Add a new section to the page

The only limit is your own imagination!

### Trouble?
If you're having trouble getting ChatGPT to do what you want, you may have to think about prompt engineering. This is the process of coming up with better prompts to elicit better responses. With the right prompt, anything is possible!

## Conclusions
While it is possible to create code very quickly using a tool like ChatGPT, it may cause issues down the line. If you do not fully understand the code you copy and paste, you may not be able to maintain your project very easily. Additionally, while ChatGPT is good at creating small things, it may not be as skilled when it comes to larger projects with many moving parts. Be aware of its limitations!

Remember, A.I. is a tool (for now)
