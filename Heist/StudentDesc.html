11/13 - Everything Is Numbers

EVERYTHING IS NUMBERS

Collaborative Corporeal Puzzle Game

THE KEYS

There are 8 keys total. You must find them all.

KEY A

KEY A is contained within BOX A. The combination will be revealed after the PAPER PUZZLES are complete.

KEY B

KEY B is contained within BOX B. You should find your starting point within BOX A.

KEY C

KEY C is contained within BOX C. You should find your starting point within BOX A.

KEY D

KEY D is contained within BOX D. Various hints and clues should appear to help you.

CRYPTEX KEY

There is one key within the CRYPTEX, which is within BOX A. Various hints and clues should appear to help you unlock the secret.

KEY-AT-LARGE

There is one key hidden in plain sight in the Hyland classroom. IMPORTANT: you should NOT open / dismantle anything to find this key. It wil be visible without touching or moving anything; from a certain vantage point, anyway. The KEY-AT-LARGE is probably closer than you expect...

FACILITATOR'S KEY

The FACILITATOR'S KEY is held by one of the facilitators. It's up to you to figure out who has it, and how to get it from them.

KEY OF THE CHOSEN ONE

Whether you know it or not, one of you should already have a key in your possession. This is the KEY OF THE CHOSEN ONE.

PRESENTATION

HINTS

It will be helpful to keep track of all the hints you have. Here are a couple to start:

  • One piece of information will help with both the CRYPTEX KEY and the KEY-AT-LARGE
  • The digits for the BOX D combination are in ascending order
