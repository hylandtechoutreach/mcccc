# Artificial Intelligence 2
This lesson introduces some interesting concepts around artificial intelligence.

### Agenda

| Activity | Time |
|-|-|
| Warm-Up | 15m |
| Critical Thinking | 15m |
| Speculative Fiction | 15m |
| Gimkit Practice | 5m |
| Gimkit Play | 10m |

## Warm-Up: Vibe Drawing
Students should follow [the instructions](VibeDrawingWarmUp.md) to create a turtle drawing or an svg graphic using vibe coding. They should submit their "drawings" using the form on the [club homepage](../BOOKREADME.md) (responses visible via link on the [club readme](README.md)).

## Critical Thinking: Presentation & Discussion
Lead into the [presentation](https://docs.google.com/presentation/d/17HV9xQQEsQ_L2_14Ha3uzu1R3L7lllN20rhp1tqCneI/edit?usp=sharing), which includes several discussion questions as well as some key term definitions.

## Speculative Fiction Activity
Each student should follow [the instructions](SpeculativeFiction.md) to consider how A.I. might affect the world of the future, and write a fictional story about it. They can start from the existing HyTOP project if they want a website that will read their story for them, or they are welcome to write in Notepad or Google Docs or on paper! They should submit their stories using the form on the [club homepage](../BOOKREADME.md) (responses visible via link on the [club readme](README.md)).

## Gimkit Practice
Students can take some time to practice the Gimkit questions linked on the [lesson homepage](StudentDesc.md). These will be the questions used in the game.
