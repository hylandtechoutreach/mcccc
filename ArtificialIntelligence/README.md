_note: the timing is incredibly flexible!_

## Icebreaker
Have students draw something using [AutoDraw](https://www.autodraw.com/), and introduce themselves along with what they drew. Follow the instructions from the [icebreaker guide](Icebreaker.md).

### Drawing
Introduce [AutoDraw](https://autodraw.com/), and show some of the basic features. Explain that the app uses artificial intelligence to try to guess what you're drawing. Make sure all the students can get to the drawing site through the club homepage, and give them some time to draw.

### Submission
After a few minutes, students should submit their auto-drawings using the form linked on the [session homepage](BOOKREADME.md). View responses in the [spreadsheet](https://hylandsw-my.sharepoint.com/:x:/g/personal/joseph_maxwell_hyland_com/EdbMjt6MqShHkev0KvEDkEoBOv3Kbo-3yxw1XwaxcD7m7A?e=zcd2YV).

### Show and Tell
Go through the responses, and call on each student. They should introduce themselves by sharing their name, grade, school, and drawing.

## Presentation
Present [this Menti presentation](https://www.mentimeter.com/app/presentation/alpvgd769dsw9evt5jj6k2n5advry69j/edit?source=share-modal) that leans heavily on student answers. There are various asides throughout the presentation where additional context can be provided; go in-depth with the [Further Reading](FurtherReading.md)

## Vibe Coding: Building a Website
Follow [the instructions](VibeCoding.md) to build a simple website using only code provided by ChatGPT.

### Corollary Demonstration: Disentangling Spaghetti
If there is time, it may be worthwhile to show a real-world example of trying to use A.I. in a software project. The [HyTop](https://github.com/hto-project/hytop) is under active development, and has some issues. Running it locally, try to debug the ["opening projects" issue](https://github.com/hto-projects/hytop/issues/133) with the help of GitHub Copilot. It may be able to do it; it may not; but it's an interesting experiment either way!
