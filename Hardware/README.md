# Computer Hardware
This session introduces the concept of hardware. It throws out a LOT of different concepts, at several different levels of hardware, from the most practical to the most theoretical. It is simply meant to expose students to a variety of different ideas that go into the working of physical computers.

### Agenda

| Activity | Time |
|-|-|
| Hardware History | 5m |
| Parts of a Computer | 10m |
| Electronic Circuits | 40m |
| Break | 10m |
| Binary Data | 20m |
| Logic Gates | 15m |
| Self-Paced Exploration | 20m |

## PowerPoint Presentation
This lesson flows through the [PowerPoint Presentation](ComputerHardware.pptx). There are pieces of lectures and activities throughout.

## Hardware History
There is a Sporcle quiz linked from the slides. This will be a good way to introduce the concept of computer hardware, dating all the way back to 2400BC. There are also some historical computer hardware pictures. This information is mainly relevant from a trivial perspective.

## Parts of a Computer
There are additional Sporcle quizzes to introduce different parts of a computer. This is not the primary focus of the session, but there is some important information about how computers work with all their component parts.

## Electronic Circuits
This portion is the actual learning. The slides introduce some of the basic components of circuits, and explain that circuits make up the inner workings of computer parts.

This section includes an interactive follow-along portion. Walk through the introductory [Tinkercad Circuits Tutorials](https://www.tinkercad.com/learn/circuits/collection/circuits-basics) (first five) with the students.

## Binary Data
This portion is also quite pertinent to computer science. Explain that everything on a computer ultimately runs on binary. There are a couple of videos that introduce the topic, and then a game to help students practice converting binary numbers into decimal, and vice versa. There are a couple of brief asides as well.

## Logic Gates
This final portion introduces logic gates, a bit more of an advanced topic. The idea is to explain that everything in a CPU can be built using these simple binary true/false operations.

## Self-Paced Exploration
Students can explore the [self-paced exploration page](HardwareSelfPaced.md) to learn more or play around with other tools.
