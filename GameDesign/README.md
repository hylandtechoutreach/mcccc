# Game Design
This lesson introduces some key concepts behind game design.

### Agenda

| Activity | Time |
|-|-|
| Platformer Hacker | 15m |
| Presentation | 15m |
| Fill-In-The-Variables Code-Along | 15m |
| Break | 15m |
| Power-Up Code-Along | 15m |
| Blooket | 15m |
| Self-Paced Time | 30m |

## Platformer Hacker
For this introductory activity, the students will compete for a high score in the [Platformer Hacker](https://hackyformer.onrender.com). Make sure to clear scores ahead of time. Some guidance can be provided, but it should be fairly intuitive.

## Presentation
Present the [Game Design PowerPoint](GameDesign.pptx).

At the end, have students [open, fork, and play](FillInTheBlankGameCodeAlong.md) the [template game](https://hytop.onrender.com/e/three-js-blank-game).

## Fill-In-The-Variables Code-Along
Once students have played the game for a bit, show them how they can customize it by changing variables. Follow the [instructions](FillInTheVariablesCodeAlong.md) to introduce these concepts in the context of this game.

## Add a POWER-UP Code-Along
Once the students have some custom games, follow [the instructions](AddPowerUpCodeAlong.md) to show them how to add a POWER-UP.

From here, they are welcome to continue developing their games and making them unique and interesting.

## Blooket
